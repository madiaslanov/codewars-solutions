# Codewars Solutions — TypeScript

My solutions to [Codewars](https://www.codewars.com/) kata, written in TypeScript and organized by difficulty level.

This repository tracks my progress in algorithmic problem-solving and helps me strengthen my TypeScript fundamentals.

## 🛠️ Technologies

- TypeScript
- Codewars

## 📊 Difficulty Levels

| Folder | Description |
|---|---|
| `kyu8/` | Beginner-level challenges |
| `kyu7/` | Beginner to intermediate challenges |
| `kyu6/` | Intermediate challenges |
| `kyu5/` | More advanced challenges |
| `kyu4/` and below | Advanced challenges |

The lower the Kyu number, the more challenging the problems generally become.
